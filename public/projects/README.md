# Project screenshots

Drop real project screenshots in this folder. Use these exact filenames so
they wire up automatically once each is added to the matching `screenshot`
field in `lib/content/products.ts`:

- `tresolv.png` — tResolv (storefront chat widget)
- `scope-ai-cv.png` — Scope AI CV
- `lenny-ai.png` — Lenny AI
- `crm-suite.png` — CRM & Business Automation Suite
- `ai-hiring-agent.png` — AI Hiring Agent
- `abz-agent-sdk.png` — ABZ Agent SDK (if one becomes available)

PNG or JPG both work. No fixed size requirement, but a 16:10-ish landscape
screenshot (roughly 1600×1000px or similar) will crop cleanest into the
site's screenshot frames.
